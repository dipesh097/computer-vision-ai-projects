## 🚀 Included Projects

### 1. 🚪 Video Entry & Exit Counter (`09-1st with entry and exit counter.py`)
- Real-time video processing pipeline utilizing **OpenCV** to track objects/people crossing dynamic entry and exit boundaries.
- Computes real-time occupancy and directional counts.

### 2. 👤 Face Recognition System (`face recognition.ipynb`)
- Deep learning model for detecting and recognizing faces from image and video streams.

### 3. 🐶🐱 Cat vs. Dog Binary Classifier (`cat vs dog.ipynb`)
- Convolutional Neural Network (CNN) built in PyTorch to classify images of pets with high accuracy.

### 4. 🔤 Russian Alphabet Character Classifier (`03_cnn on russian_alphabates.ipynb`)
- CNN architecture trained on character datasets for handwritten symbol recognition.

### 5. 🖼️ PyTorch Data Augmentation Pipeline (`using transforms.ipynb`)
- Image preprocessing workflows using `torchvision.transforms` (scaling, rotation, normalization, color jitter).

## 🛠️ How to Run

```bash
# Clone repository
git clone https://github.com/dipesh097/projects.git
cd projects

# Install required packages
pip install opencv-python torch torchvision matplotlib numpy jupyter

# Run OpenCV Entry/Exit Counter script
python "09-1st with entry and exit counter.py"

# Or launch Jupyter for notebooks
jupyter notebook
```
